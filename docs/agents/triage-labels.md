# Triage labels

The engineering skills use five canonical triage roles. This table maps those
roles to the labels used by this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The issue is waiting for more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an autonomous agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or judgement. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill names a canonical role, use the corresponding GitHub label.
